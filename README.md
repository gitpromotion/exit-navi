# EXIT NAVI — KSPO DOME 구역별 시차 퇴장 안내 서비스

실감형 콘텐츠(KSPO DOME 3D 모델)와 공공데이터로 설계한 퇴장 안내 웹사이트입니다.
2026 한국체육산업개발(주) 공공데이터 활용 경진대회 출품작.

## 페이지
| 파일 | 내용 |
|---|---|
| index.html | 홈 (문제·해결·결과 요약) |
| find.html | 관객용 내 구역 출구 찾기 (`find.html#z=18` 처럼 구역 지정 가능) |
| operator.html | 운영자 안내 방송판 |
| sim.html | 3D 퇴장 시뮬레이션 (발표·분석 모드) |
| story.html | 스크롤 스토리 |
| about.html | 활용 데이터·분석 방법·결과 |

## 실행
- 서버 없이 `index.html`을 더블클릭해도 열립니다.
- 또는 이 폴더에서 `python -m http.server 8000` 후 http://localhost:8000

## 데이터
- `js/data2.js`: 시뮬레이션·최적화 결과 (출구 문 폭 2.35m, 총 관객 15,948명 기준)
- 줄 인원·대기시간은 실제 데이터를 바탕으로 한 시뮬레이션 결과입니다.
- 활용 데이터: 한국체육산업개발(주) KSPO DOME 3D 모델·올림픽공원 공연정보·KSPO DOME 평면도/좌석배치도,
  KOPIS 공연정보, 서울시 지하철 역별 시간대 승하차, 기상청 ASOS, 한국천문연구원 특일정보 (2025년)
